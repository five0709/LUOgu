## 本地运行

### 1. 准备环境

- 安装 Git 和 GNU G++，确保 `git`、`g++` 可以在终端中直接运行。
- 当前代码使用 `<bits/stdc++.h>`，建议使用 GCC / MinGW 的 G++ 工具链。
- 以下示例按 C++14 编译。

```bash
git clone https://github.com/five0709/LUOgu.git
cd LUOgu
```

### 2. 编译并运行一道题

以 P1601「高精度加法」为例，在仓库根目录打开 PowerShell：

```powershell
g++ -std=c++14 -O2 "P1601 高精度加法.cpp" -o p1601.exe
.\p1601.exe
```

程序启动后输入：

```text
999
1
```

预期输出：

```text
1000
```

Linux 下可将输出文件名改为 `p1601`，然后运行 `./p1601`。编译其他题目时，将命令中的源文件名替换为对应文件名；包含空格的文件名需要保留引号。

### 3. 在 VS Code 中编译

安装 Microsoft C/C++ 扩展，并确保 `g++.exe` 位于 Windows 的 `PATH` 中。打开需要编译的 `.cpp` 文件，按 `Ctrl+Shift+B`，选择「C/C++: g++ 编译当前文件」。生成的 `.exe` 位于源文件旁，可在终端中运行。

## 复盘与改进

以下事项来自对当前实现的检查，作为接下来复盘的起点：

- [ ] **P1098 · 字符串边界**：处理 `-` 前先检查左右字符是否存在，覆盖连字符位于开头、结尾等情况，避免越界访问。
- [ ] **P1255 · 递推与高精度**：将递归枚举改为 `f(n) = f(n - 1) + f(n - 2)` 的递推，并使用高精度存储结果，解决重复计算与整数溢出问题。
- [ ] **P1304 · 素数判定**：将试除条件 `i * i < n` 改为 `i * i <= n`，补充 4、9、25 等完全平方数的检查。
- [ ] **P1518 · 无解判断**：记录双方的位置和朝向，出现重复的联合状态时判断无解，替换固定 1000 步的截断条件。
- [ ] 为每道题补充思路、复杂度分析和有代表性的边界用例，再同步更新本页。

## 记录约定

后续新增或复盘一道题时，尽量完成以下几项：

1. 在题目索引中添加原题链接、知识点和源码链接。
2. 在源码注释或单独笔记中记录核心思路、时间复杂度与空间复杂度。
3. 检查最小输入、临界值及特殊情况；高精度题重点检查进位和零，模拟题重点检查方向、边界与终止条件。
4. 提交信息写明题号与具体变化，方便回看实现过程。

提交信息示例：

```text
feat(P1601): 添加高精度加法实现
fix(P1304): 修正完全平方数的素数判定
docs(P2240): 补充贪心思路与复杂度分析
```
